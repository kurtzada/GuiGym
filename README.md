# GuiGym V6 — Evolução & Performance

Aplicativo de treinos para hipertrofia, com identidade preta e vermelha, interface mobile e funcionamento offline (PWA).

## Recursos
- Fila inteligente: faltar não pula o treino pendente.
- Treino personalizado com séries, repetições e cargas.
- Cronômetro automático após cada série; descanso maior para pernas.
- Low volume opcional por sessão.
- Hidratação diária com meta e registros rápidos.
- Conquistas, histórico, progressão e relatórios.
- Exportar/importar backup JSON.

## GitHub Pages
Em **Settings → Pages → Build and deployment**, escolha **Deploy from a branch**, **main**, **/(root)** e clique em **Save**. Endereço esperado: https://kurtzada.github.io/GuiGym/ (só funciona depois da publicação ser habilitada).

## Dados
Os dados ficam no armazenamento local do navegador, sem sincronização entre dispositivos. Exporte backups regularmente.
